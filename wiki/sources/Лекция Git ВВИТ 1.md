## Why this source matters

Эта лекция важна, так как вводит понятие системы контроля версий. В ней подробно разбирается устройство Git, работа с репозиториями, коммитами и ветками. Освоение всех команд, описанных в лекции, необходимо для дальнейшего обучения и командной разработки.

## Reliable extract

1.Git - это распределённая система контроля версий. Она нужна для сохранения истории проекта, сохранение каждого изменения с возможностью управлять разными версиями проекта. (слайд 6) 2.Репозиторий - это хранилище, в котором Git сохраняет историю проекта (слайд 13) 
3.Коммит - зафиксированное изменение в истории проекта, попадает только то, что было добавлено в индекс. Важно добавлять коммиты с информативными подписями, которые отражают суть изменения (слайд 16) 4.Файл .gitignore - это обычный текстовый файл в корневой папке проекта, сюда добавляем всё то, что не должно попасть в публичны доступ (на GitHub) (слайд 38)

## Limitations

Лекция объясняет лишь базовое понимание работы Git и связанных с ним команд, содержит только базу, не рассматривает никаких сложных сценариев
